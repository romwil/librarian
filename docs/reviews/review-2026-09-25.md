**Scope:** Living-library arc through ~0.5.2 on `main` (tree audit; not a branch diff).

**Version under review:** `0.5.2` (`librarian/_version.py`).

## 1. The Architectural Verdict

### Cruft (Immediate excision candidates)

- **`librarian/web/route_imports.py` star-import hub (~433 lines)** — every router does `from librarian.web.route_imports import *`. The 0.4.20 split moved files without ending the monolith import surface; routers still share an implicit global dependency bag.
- **Seven near-duplicate progress facades** (`enrich_progress.py`, `ingest_progress.py`, `scan_progress.py`, `extra_files_reprocess_progress.py`, `purge_duplicates_progress.py`, `purge_shells_progress.py`, `split_mixed_kinds_progress.py` — ~1.5k LOC atop `ProgressJob`) — thin wrappers that should collapse to one typed factory.
- **Lexicon residue:** `librarian/web/routers/review.py:1` still says “Review bagging”; frontend already maps `#bagging` → shelving. Finish the rename or delete the alias once UI hashes settle.
- **Deprecated NYT list routes** still ship `deprecated: True` payloads in `catalog.py` — keep only if an old client still calls them; otherwise delete.

### Structural Seams (Refactor required before further feature growth)

1. **`public_work` is not a public shape** — `librarian/web/serializers.py:10-18` shallow-copies the SQLite row. Storage fields (`folder_path`, `cover_path`, `atmosphere_path`, etc.) ride every Hall/browse/work response. Domain purity is broken at the transport boundary.
2. **God router `catalog.py` (~991 lines)** — Hall, search, browse, works, covers, download/stream, queue, gaps, metadata. Further feature growth here will keep re-coupling authz, disk IO, and indexer payloads.
3. **Indexer disclosure boundary is inconsistent** — `strip_secret_query` exists and is tested for *job persistence*, but live Find-beyond hits and `compact_candidate` still ship raw `download_url` / `raw` indexer blobs to authenticated clients (including readers).
4. **SPA catch-all serves files without a root jail** — `create_app`’s `/{full_path:path}` joins into `FRONTEND_DIST` without `resolve().relative_to(...)`. Unauthenticated static delivery is a separate trust zone from `/api/` and must be confined.

### Hardened Wins (Patterns to standardize across the repo)

- **Explicit public handshake** (`PUBLIC_HANDSHAKE_EXACT` in `librarian/auth.py:27-36`) — no `/api/auth/` wildcard; fail-closed middleware in `app.py:100-114`.
- **Proxy trust opt-in** (`librarian/proxy.py`) — `X-Forwarded-*` ignored unless `LIBRARIAN_TRUST_PROXY_HEADERS=1`; Secure cookies and rate-limit keys stay honest on LAN binds.
- **Session secret refuse-default** + auto-persist under `/config/session_secret` mode `0600` (`librarian/sessions.py`).
- **Password verify uses `hmac.compare_digest`** + dummy hash path for missing users (`librarian/auth.py:58-71`).
- **Invite redeem is one SQLite transaction** (`create_local_user_and_redeem_invite`).
- **`BackgroundJobSlot.start_if_idle`** evaluates progress + live thread under one lock (race closed in 0.4.20 era).
- **Settings secret retain-on-blank + mask** (`merge_secret_fields` / `mask_settings` in `librarian/config.py`) — including mail nested secrets.
- **`/data` confinement for ingest/fs** (`confined_path` in `librarian/ingest.py:72-97`).
- **Description HTML allowlist sanitizer** before `dangerouslySetInnerHTML` (`frontend/src/description.js`).
- **WriteSerializer** single-writer queue for SQLite mutations (`librarian/db_write_serializer.py`).

## 2. Detailed Findings Register

### P3-CRIT-01 — Unauthenticated SPA path traversal

- **Category:** Security
- **Severity:** Critical
- **Location:** `librarian/web/app.py:144-151`
- **The Reality:** The catch-all SPA handler joins `FRONTEND_DIST / full_path` and serves any path where `candidate.is_file()` is true. On POSIX, `Path.is_file()` follows `..` segments. This route is **outside** the `/api/` auth gate (`app.py:104-105`). A crafted path such as `assets/../../../../etc/passwd` (or equivalent encoded form that still reaches the route parameter) can read any file the process user can open — session secret under `/config`, `settings.json`, SQLite, host files mounted into the container.
- **Mitigation Code:**

```python
@app.get("/{full_path:path}")
def spa(full_path: str):
    root = FRONTEND_DIST.resolve()
    if full_path:
        candidate = (root / full_path).resolve()
        try:
            candidate.relative_to(root)
        except ValueError:
            candidate = None
        else:
            if candidate.is_file():
                return FileResponse(candidate)
    index = root / "index.html"
    if index.is_file():
        return FileResponse(index)
    return JSONResponse({"detail": "SPA is not built"}, status_code=404)
```

- **Category:** Performance
- **Severity:** Critical
- **Location:** `librarian/web/routers/catalog.py:839-864`

@app.post("/api/queue/tick")

    require_role(request.state.user, "owner", "op")

### P3-HIGH-03 — Owner/op `cover_url` is server-side SSRF

- **Category:** Security
- **Severity:** High
- **Location:** `librarian/enrich.py:817-835` (via `WorkMetadataPayload.cover_url`); `librarian/covers.py:64-87` (`httpx.Client(..., follow_redirects=True)` with no URL allowlist)
- **The Reality:** Metadata PATCH accepts any URL; the server fetches it (redirect-following) and writes bytes under the work folder. That reaches cloud-metadata endpoints, LAN admin UIs, and internal SAB/indexer hosts from the Unraid network namespace.
- **Mitigation Code:**

```python
from urllib.parse import urlparse

_ALLOWED_COVER_HOST_SUFFIXES = (
    "openlibrary.org",
    "covers.openlibrary.org",
    "coverartarchive.org",
    "hardcover.app",
    # extend via settings allowlist
)

def assert_safe_cover_url(url: str) -> str:
    parsed = urlparse(url.strip())
    if parsed.scheme not in {"http", "https"} or not parsed.hostname:
        raise ValueError("Cover URL must be http(s)")
    host = parsed.hostname.lower().rstrip(".")
    if host in {"localhost", "127.0.0.1", "::1"} or host.endswith(".local"):
        raise ValueError("Cover URL host not allowed")
    # Block link-local / private IP literals (expand with ipaddress module)
    if not any(host == s or host.endswith("." + s) for s in _ALLOWED_COVER_HOST_SUFFIXES):
        raise ValueError("Cover URL host not allowed")
    return url
```

Call before `fetch_cover_with_fallback`; prefer `follow_redirects=False` or re-validate each hop.

### P3-MED-01 — Password verify short-circuits on malformed salt

- **Category:** Security
- **Severity:** Medium
- **Location:** `librarian/auth.py:61-71`
- **The Reality:** Missing `$` runs a dummy PBKDF2 (good). Invalid hex salt returns `False` **without** dummy work, enabling a cheap timing distinction for corrupted vs present hashes (low practical value today, but breaks the constant-time story).
- **Mitigation Code:**

```python
def verify_password(password: str, stored_hash: str) -> bool:
    if "$" not in (stored_hash or ""):
        verify_password("!", _DUMMY_PASSWORD_HASH)
        return False
    salt_hex, expected_hex = stored_hash.split("$", 1)
    try:
        salt = bytes.fromhex(salt_hex)
    except ValueError:
        verify_password("!", _DUMMY_PASSWORD_HASH)
        return False
    derived = hashlib.pbkdf2_hmac("sha256", password.encode("utf-8"), salt, _pbkdf2_iterations())
    return _hmac.compare_digest(derived.hex(), expected_hex)
```

### P4-MED-02 — Remote cover URLs loaded directly in the browser

- **Category:** Privacy
- **Severity:** Medium
- **Location:** `frontend/src/cover.js:340-346` (`coverWashUrl`); `frontend/src/components/CoverCard.jsx:56`
- **The Reality:** When `has_cover` is false, the client uses naked `work.cover` / `work.cover_url`. Browser requests reveal member IP and library taste to third-party CDNs; URLs may still carry query tokens if scrubbing fails (pairs with P3-CRIT-02).
